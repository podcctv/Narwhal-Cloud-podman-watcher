# 独立代理管理面板策略（1.7.40）

按管理员选定策略，S-ui/X-ui 安装本身只提醒，不作为禁止业务、机场对接或已确认弱密码的结论。

节点在进程采样中识别 `sui`、`s-ui`、`x-ui`、`3x-ui` 的精确 comm 和 argv[0]，不会因命令文本包含名称就命中。
告警 `standalone_proxy_panel` 为 warning/security_attention，保存面板类型、PID 及该 PID 实际持有的监听端口。
不把容器中其他程序的端口归到面板，不上传 argv 原文，不尝试默认密码登录，不读取或还原密码哈希。

该提示不进入自动停止、自动买家推送或自动 SSH banner 流程。
管理员可放行、忽略或使用“通知用户”明确发送买家 API/Telegram 与 SSH 登录后提醒。
已经确认的空/弱密码 SOCKS、异常行为、机场对接仍走各自既有的证据与处置门槛，安装面板不会降低这些门槛。
`panel_auth_status=not_assessed` 明确表示尚未核验面板登录口令，不能解释为密码安全。
