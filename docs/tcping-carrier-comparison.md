# TCP PING 三网对比（1.7.37）

默认按电信、联通、移动分别展示。电脑三张地图并排，850px 及以下使用运营商按钮切换地图；省份三网对照表始终显示三网数据。单网明细保留地图与节点列表并排布局。

- 三图使用相同固定时延色阶和地图比例，省份选择同步；省份表格提供键盘操作入口。
- 省份时延是该运营商有效目标时延的中位数。市级和全量记录也按省份、运营商分别汇总，绝不跨运营商混算。
- TCP 成功 / 尝试次数只统计已经返回的实际尝试。DNS 失败可能没有 TCP 尝试；未返回不计作失败。
- 部分成功、超时、DNS 失败、未返回和无目标分别展示。地图黄色描边提示含失败或部分成功，表格保留具体状态，避免仅靠颜色判断。
- 对照表支持失败 / 部分成功优先、高时延优先及省份排序。指定目标（包含台湾）独立展示，不假定其运营商。
- 节点明细的运营商 / 状态筛选只影响明细；三网对比始终保留失败背景。点击省份同步聚焦，点全国视图返回。
- 仅改变展示，不修改目标目录、测量方向、任务、冷却、历史记录或购买链接。一次测试不代表长期网络质量。

本地验证：`node tests/test_tcping_carriers.cjs`；静态产物通过 loopback HTTP 8795 服务后运行 `node tests/test_tcping_carriers_ui.cjs`。UI 测试拦截为合成 API 数据，不启动真实探测。覆盖 375/768/1024/1440px、横屏、减少动画、键盘聚焦、排序、单网模式和失败状态。
